Word HideRx
├── Layout
│   ├── Collapsible sidebar (CSS-only toggle)
│   │   └── Auto-collapses below 701px, auto-expands above
│   ├── Workspace (grid + exam viewer)
│   └── Mobile mode (fixed viewport height, stacked layout)
│
├── Spreadsheet (2 columns: A / B)
│   ├── Editable cells, auto-saved to localStorage
│   ├── Paste handling (tab/newline → rows & columns)
│   ├── Sort A–Z / Z–A per column (rows stay paired)
│   ├── Resize handles (column width, grid height)
│   └── Hide/Show column (masks words)
│
├── Mock exam (opens when a column is hidden)
│   ├── Mode switcher (red animated underline)
│   │   ├── Typing (type answer → Check)
│   │   ├── Multiple choice (1 correct + 3 distractors)
│   │   ├── True / False
│   │   └── Select all that apply (duplicate A prompts = multiple answers)
│   ├── Check Answer + Next buttons (50% each, one row)
│   ├── Shuffled deck (full cycle before repeats, no back-to-back repeat)
│   ├── Mode switch keeps the same question
│   └── Clear Columns also resets the exam
│
├── Text-to-speech
│   ├── Read / Pause / Stop
│   ├── Loop on/off
│   ├── Speed slider

│   └── Chunked reading
│
├── Timer (runs while reading; reset button)
├── Metrics (char count, estimated time)
